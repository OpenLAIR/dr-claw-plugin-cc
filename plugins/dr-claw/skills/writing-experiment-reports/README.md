# Writing Experiment Reports — Claude Code Skill

**Version:** 1.0 (2026-01-26)

## Purpose
Automatically generate comprehensive LaTeX experiment reports for machine learning ablation studies. Creates publication-ready documents with equations, visualizations, tables, and analysis in timestamped Overleaf folders.

## Triggers
This skill activates when you ask Claude to:
- "Create report on [experiment]"
- "Generate latex report comparing [X] vs [Y]"
- "Make comprehensive report for ablation study"
- "Create overleaf report for [experiment]"
- "Generate experiment documentation"

## What It Does
1. **Fetches training data** from WandB, CSV files, or checkpoint directories
2. **Creates clean visualizations** (removes empty subplots, publication-quality)
3. **Generates LaTeX report** with:
   - Mathematical formulations
   - Detailed comparison tables
   - Training dynamics figures
   - Full methodology, results, analysis, conclusion
   - Hypothesis validation
4. **Organizes files** in timestamped folder in your Overleaf Dropbox directory
5. **Includes supporting files**: README, CSV data, plain text summary

## Typical Output Structure
```
experiment-report-YYYYMMDD_HHMMSS/
├── main.tex                      # Complete LaTeX report
├── experiment_comparison.png     # Training dynamics (3-4 panels)
├── experiment_key_metrics.png    # Detailed analysis (4 panels)
├── experiment_detailed.csv       # Raw comparison data
├── experiment_summary.txt        # Plain text summary
├── README.md                     # Usage instructions
└── build.sh                      # Compilation helper
```

## Example Usage

### Example 1: Citation Reward Ablation
**You:** "Create comprehensive report on citation reward ablation, baseline run udm1u2ap vs citation run 88lhl157"

**Claude will:**
1. Fetch WandB data for both runs
2. Create 2 figures comparing validation accuracy, KL divergence, test set improvements
3. Generate 20-page LaTeX report with composite reward equation
4. Create folder: `citation-reward-ablation-20260126_082436/` in Overleaf directory
5. Include detailed CSV with 17 test sets

### Example 2: Model Comparison
**You:** "Make report comparing LLM vs CNN/SVM baselines on Sonics8K"

**Claude will:**
1. Ask for data sources for each model
2. Create comparison bar charts and performance tables
3. Generate report analyzing whether LLM's complexity is justified
4. Validate hypothesis about reasoning benefits

## Quality Standards
Reports generated by this skill include:
- ✅ Numbered equations with LaTeX formatting
- ✅ Clean visualizations (no empty subplots)
- ✅ Detailed comparison tables
- ✅ Hypothesis validation with evidence
- ✅ Professional academic writing style
- ✅ Publication-ready figures (150 DPI)

## Limitations
- Requires actual experimental data (won't generate fake results)
- LaTeX only (not Word or Markdown)
- Focused on ML experiment comparisons (not general reports)
- Assumes Dropbox sync for Overleaf integration
